# py-kernel

Низкий уровень не обязан быть адом.

Мы делаем тулы, гайды и примеры для тех, кто пишет что-то близкое к железу: драйверы, прошивки, ядра и всё такое. Идея простая. Порог входа в lowlevel кажется высоким в основном потому, что всё плохо объяснено, инструменты разбросаны, а половина гайдов в сети давно устарела. Это можно починить.

Что мы стараемся делать:

- объяснять подробно, чтобы не пришлось гуглить каждое второе слово
- чтобы код реально собирался и запускался
- чтобы не нужна была плата там, где можно обойтись без неё
- писать, на каких версиях всё проверено

Сейчас есть [rust-drivers-from-zero](https://github.com/py-kernel/rust-drivers-from-zero). Это гайд про драйверы на Rust. Дальше будет больше.
